# Доза.История — ТЗ

Личная веб-платформа для подготовки к ЕГЭ по истории. Учу с нуля, начиная с Рюрика, по скриптам репетитора.
Новая тема появляется каждую среду. Хуже всего запоминаются даты и имена: весь сайт работает на это.

Исходники: `E:\ЕГЭ\История` — скрипты PDF (рукописные, из Notein, важное выделено красным) и презентации репетитора (печатный текст картинками).

## Платформа
- GitHub Pages + Firebase: вход через Google, прогресс в Firestore, одинаковый на телефоне, планшете и ноуте.
- PWA: ставится как приложение, работает офлайн, синхронизация при появлении сети.
- Светлая и тёмная тема: по умолчанию как в системе, плюс переключатель.
- Одинаково удобно на телефоне, планшете и ноутбуке.
- Напоминаний нет (можно добавить потом).
- Только история (обществознание не делаем).

## Как добавляются темы
- Основной путь: пользователь кидает скрипт (PDF) и/или презентацию в чат, Claude расшифровывает и публикует новую версию.
- Текст берётся из презентации, а то, что выделено красным в скрипте, — «главное»: подсвечивается, чаще попадает в тесты и в «дату дня».
- По всему материалу Claude дополнительно ищет даты и факты, которые бывают на ЕГЭ, и добавляет их.
- Тема 4 «Феодальная раздробленность»: скрипта нет, делать по презентации.
- Тема открыта, если загружен её конспект. Будущие темы (есть презентации: Невский, Москва, Грозный) видны в списке с замком.

## Разделы
### Главная
- Основной экран со списком тем, посередине отдельная плашка «Дата дня» (проверка вчерашней + новая дата).

### Темы и прохождение
- Вид как у скрипта, но красивее: разделы 1-2-3, карточки дат с иконками, блоки «причины/итоги», карточки князей.
- Вкладка «Мой скрипт»: оригинальные страницы картинками с увеличением.
- Доп. материалы: видео YouTube (подбирает Claude), «Интересное» (детали для запоминания и для ЕГЭ), термины (общий словарь).
- Тест по теме: ~15–20 вопросов, микс вопросов по конспекту и реальных заданий ЕГЭ, порядок перемешивается.

### Общее повторение (даты)
- Общий список дат изученных тем.
- Форматы: карточки-перевёртыши, ввод года, выбор из 4 (похожие ловушки), найди пары, век/четверть века (репетитор иногда спрашивает только век), дата ↔ правитель. Плюс задания ЕГЭ на хронологию.
- Интервальное повторение без обязаловки: слабые даты появляются чаще, счётчика «на сегодня» нет.
- Мнемоники: у каждой важной даты и князя есть мнемоника от Claude, пользователь может дописать свою (синхронизируется).

### Дата дня
- Каждый день одна новая дата по хронологии с Рюрика, только «красные» (главные) даты.
- На следующий день проверка: вчерашняя + 2–3 старые, потом новая.
- Ошибся — идём дальше, дата уходит в «слабые».
- Догнали последнюю пройденную тему — ждём новую тему, пока только повторение.

### Правители
- Родовое дерево: правители + важные родственники (Борис и Глеб, Андрей Боголюбский, Ольга, Софья Палеолог и т. п.), отдельно «чужие» правители (Батый). Только из пройденных тем: дерево растёт с темами.
- Тап по князю: подсветка его ветки, карточка: портрет (из конспектов, иначе Википедия), годы правления, родство словами с кликабельными именами, события с датами, темы, где встречается, мнемоника, задания ЕГЭ про него, кнопка «проверь меня», полоска «насколько знаешь».

### Тесты (бесконечные)
- Все изученные темы вперемешку.
- Типы заданий ЕГЭ: хронология и даты, соответствия (личности, процессы, факты, термины), работа с источником, карты и культура (иллюстрации). Задания собирать из открытого банка ФИПИ и «Решу ЕГЭ».
- Поощрение: опыт и звания (смерд → дружинник → боярин → князь → великий князь → царь), достижения, комбо и рекорды. Серии дней нет.
- Устного опроса нет.

## Дизайн
- На базе arzamas.academy: журнальная вёрстка, шрифт с засечками, много воздуха, крупные иллюстрации.
- «Старины» совсем капельку.
- Сначала макет, потом сайт.
- Тексты: просто, на «ты», без тире-вставок и лозунгов.
